知屿计划 · Zhiyu AI

项目愿景

打造一个能够持续运行、自主规划、使用工具、拥有长期记忆并不断总结经验的 AI 助手。

核心目标

- 自主规划与执行多步骤任务
- 长期记忆与经验总结
- 支持调用外部工具
- 定期检查目标并规划下一步行动
- 支持更换底层 AI 模型

技术路线

- 编程语言：Python
- 数据存储：SQLite
- AI 模型：优先考虑 Claude API
- 运行环境：后续部署到 Linux 云服务器
- 代码管理：GitHub

开发原则

1. 从最小可运行版本开始。
2. 优先使用免费开发资源。
3. 保护 API 密钥与个人数据。
4. 每个阶段都进行测试。
5. 预留预算限制、权限控制和紧急停止机制。

当前阶段

第一阶段：准备开发环境，学习 Python 基础，搭建最小可运行 AI Agent。# zhiyu-ai
